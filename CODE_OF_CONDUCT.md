# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming, whatever someone's experience level.
- Give and accept constructive feedback gracefully.
- No harassment, insults, or personal attacks.
- Don't publish other people's private information. That includes VINs and sensor IDs from someone else's logs.

Report unacceptable behaviour to the maintainers by opening a private [security advisory](../../security/advisories/new) or contacting a maintainer directly. Reports are handled confidentially. Maintainers may remove comments, commits, or contributors that break these rules.
